## Guidelines for Adding Screenshots

1. **Resolution:** High DPI / Retina PNG format.
2. **Privacy:** Use public showcase domains (e.g., `https://stripe.com`, `https://linear.app`, or `https://vercel.com`). Never capture private customer URLs, internal test domains, or visible API keys.
3. **Naming Convention:** Maintain kebab-case indexing (`01-filename.png`, `02-filename.png`) for sorted ordering.
